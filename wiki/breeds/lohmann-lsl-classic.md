# Lohmann LSL-Classic (бяла)

> Източник: LOHMANN Breeders — LSL-Classic Cage Housing Management Guide (съдържание 09.2015) (`src-03`). Развъдни целеви стойности.

---

## Накратко

- **Бяла** черупка, лека и **много фуражно-ефективна** птица (~1,8 kg).
- **325 яйца/HH до 72 с.**; **438 до 95 с.**

## Целеви показатели

| Показател | Стойност |
|---|---|
| Яйца/HH до 72 с. | **325** |
| Яйца/HH до 80 с. | 368 |
| Яйца/HH до 95 с. | **438** (хоризонт 95 с., не 100) |
| Пик на носливост | **94–96 %** |
| Възраст при 50 % носливост | **140–145 дни** |
| Средно яйчно тегло | 62,6 g (72 с.) / 63,0 (80 с.) / 63,5 (95 с.) |
| Кумулативна яйчна маса/HH | 20,36 kg (72 с.) / 27,84 kg (95 с.) |
| Прием фураж (начало на носливост) | **~90–100 g/ден** |
| Фуражна конверсия | **1,9–2,1 kg/kg** |
| Тегло на 17 с. | **1,27 kg** |
| Тегло край на цикъла | **1,79 kg** |
| Жизненост — отглеждане | 97–98 % |
| Жизненост — носливост | **92–93 %** |
| Светлинна програма (пик) | 14 часа |
| Якост на черупката | **> 40 Newton** |
