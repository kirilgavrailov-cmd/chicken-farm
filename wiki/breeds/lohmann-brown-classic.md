# Lohmann Brown-Classic

> Източник: LOHMANN Breeders — Performance Data sheet `08.21_V01-21` (авг. 2021) + Cage Housing Management Guide (`src-03`). Стойностите са **развъдни целеви** при идеални условия.

---

## Накратко

- **Кафява** черупка, персистентна носачка с цикъл до **100 седмици**.
- **323,8 яйца/HH до 72 с.**; **461,1 до 100 с.**
- Черупка с якост на счупване **> 40 N**.

## Целеви показатели

| Показател | Стойност |
|---|---|
| Яйца/HH до 72 с. | **323,8** |
| Яйца/HH до 80 с. | 366,8 |
| Яйца/HH до 100 с. | **461,1** |
| Пик на носливост | **94–96 %** |
| Възраст при 50 % носливост | **140–145 дни** |
| Средно яйчно тегло | 63,7 g (72 с.) / 64,1 (80 с.) / 64,9 (100 с.) |
| Кумулативна яйчна маса/HH | 20,63 kg (72 с.) / **29,92 kg (100 с.)** |
| Прием фураж (носливост) | **110–120 g/ден** (20 °C) |
| Фуражна конверсия | **2,0–2,2 kg фураж / kg яйчна маса** |
| Тегло на 17 с. | **1,42 kg** (≈ 1 493 g на 18 с.) |
| Тегло край на цикъла | **2,06 kg** |
| Жизненост — отглеждане | 98–99 % |
| Жизненост — носливост (72 с.) | **95–96 %** |
| Жизненост — носливост (100 с.) | 90–91 % |
| Светлинна програма (пик) | **14 часа** (затворен обор; от 21 с. до края) |
| Якост на черупката | **> 40 Newton** |

> Флаг: точна възраст на пика не е дадена като число в датасийта (само крива).
